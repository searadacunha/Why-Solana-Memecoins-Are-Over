# Reliability audit, 4 November 2026

Base: `main` at `6565245e3f5d48b0e6a987ebe6f2aa5954fb00be`.

This review inventories the published code, runs the available offline checks,
and adds regression tests for confirmed implementation defects. It does not
reconstruct the unpublished captures or certify every scientific conclusion.
No README, published result, original dataset, frozen script or registry is
changed by these corrections.

## Confirmed defects corrected

| Component | Failure reproduced before the fix | Corrected behavior |
| --- | --- | --- |
| `code/lib_verif.py` | An empty page after exactly 1,000 signatures reports a censored history, even though the walk reached its end. An entirely empty history has the same incorrect flag. | Natural termination returns `censored=False`; exhausting the 40-page budget remains censored. |
| `code/pumplib.py` | Empty groups count toward the three-cluster minimum. Zero usable clusters crash; one or two usable clusters produce an interval despite the minimum. | The minimum applies after removing empty groups. Valid nonempty inputs retain their estimator, seeds and results. |
| `code/rpc_client.py` | Two writers to the same cache key share one temporary filename. A controlled concurrent run raises `FileNotFoundError` after one writer moves the other's file. Failed JSON serialization also leaves a partial temporary file. | Each writer uses a unique temporary file and atomically replaces the destination. Temporary files are cleaned on a failed serialization. |
| `post_detection_forensics/code/frpc.py` | The paced collector accepts missing RPC results as `None`, and falsey non-array signature results as empty histories. Ten malformed-response regression cases fail on the previous code. | Missing results and non-array signature pages raise `HeliusError`. Explicit transaction `null`, a genuine empty signature array and explicitly tolerated RPC codes retain their meanings. |

The regression inputs are synthetic test fixtures in temporary directories or
mocked transports. They are never added to the investigation datasets.

## Validation

Environment: CPython 3.12.14, pytest 9.2.0, Ruff 0.17.3 and mypy 2.4.1.

- The baseline has 95 passing tests. The corrected suite has **115 passing tests**.
- All 232 Python files present at the base parse successfully. Ruff checks the
  complete checkout with the existing configuration; strict mypy passes on the
  12 modules named by CI. These checks do not establish semantic correctness of
  every line in the 49,419-line Python inventory.
- `python code/run_all.py --deps` reports 67 core modules and no undeclared
  third-party imports. Optional plotting imports remain allowed.
- `python code/run_all.py --strict` runs the 22 available offline scripts,
  skips 20 scripts with explicit reasons, and compares the declared artifacts.
  The compared artifacts remain unchanged byte for byte.
- The README claim ledger still agrees on its 43 sourced claims. Its 15
  unchecked narrative figures remain unchecked; this comparison is not an
  independent validation of the underlying observations.
- `python alpha_patterns/code/chk_00_integrity.py` verifies 17 published frozen
  files and the recorded preregistration hashes. Its registry comparison reports
  25 matching references, 11 historical superseded references and 6 references
  to unpublished files; that third check is descriptive.
